# Season Checker

A simple, interactive Java console application that takes a month as input from the user and determines which season it belongs to. 

This project demonstrates the use of **Java 14+ Enhanced Switch Expressions** (arrow syntax) and basic input handling with `Scanner`.

## Features
- Case-insensitive input handling (`.toLowerCase()`)
- String trimming to handle accidental whitespace
- Uses modern Java arrow switch syntax (`->`) for clean code
- Handles invalid inputs gracefully with a `default` case
